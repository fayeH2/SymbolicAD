# Core MVTec LOCO pipeline

The maintained path is intentionally small:

1. `neurosymbolic_fsad/data.py`: train-only, nested, seed-sensitive supports.
2. `scripts/train_generic_inpformer.py`: isolated INP-Former training with
   component-loss and gradient convergence records.
3. `scripts/evaluate_loco_checkpoint.py`: image-level all/logical/structural
   evaluation with valid good-image controls.
4. `neurosymbolic_fsad/ovd_grounder.py` + `entity_bridge.py`: grounded rule
   atoms and rule-local INP confirmation.
5. `symbolicdet_evolution.py`: support-only monotone AND/OR higher-order search.

The current GroundingDINO compiler represents one repeated entity type. On
LOCO it is a deliberately labeled **single-entity control**, not the final
multi-entity model. Cross-type composition and relation rules must be grounded
before claiming that the logical gap is closed.

The removed `run_loco_experiment.py`, `run_loco_enhanced.py`, and
`train_loco_inpformer.py` were not retained as compatibility wrappers: they
hard-coded the missing `NeuroSymbolic_FSAD` path, used an unrelated MVTec
transistor checkpoint or the old contaminated support protocol, and evaluated
logical anomalies without good controls. Their outputs cannot support a LOCO
claim.

Official sPRO@5% FPR must remain unreported until the original LOCO defect
configuration/evaluation package is restored. Global pixel AUROC is not a
drop-in replacement.

## Generality claim and falsification contract

The maintained pipeline is **not yet a universally validated method**.  Its
current status is:

- reusable mechanism: INP feature inference, positive monotone AND/OR ASTs,
  support-only calibration, provenance checks, and fail-closed rule loading;
- LOCO-specific evaluation: five fixed classes and defect-family names;
- single-entity control: the current Qwen/OVD schema represents at most one
  repeated foreground entity and therefore cannot express cross-type rules;
- unverified transfer: no frozen V12/V13 multi-entity implementation has yet
  passed an unseen non-LOCO dataset.

"One processing flow" means one set of stage contracts, not one detector or
one predicate forced onto every visual domain:

```text
DatasetSpec -> normal supports -> entity/attribute observations
            -> typed atoms -> support calibration / abstention
            -> monotone program -> witness maps -> conservative fusion
            -> one evaluator + one visualization manifest
```

Dataset adapters may define discovery, masks and official metrics.  Grounders
may implement domain-appropriate observations, but every implementation must
emit the same typed-atom and witness-map interface. Unknown predicates,
unstable grounding, unsupported K, or missing official evaluation metadata
must abstain rather than silently substitute another computation.

Before a generality claim, freeze code and hyperparameters and pass all of:

1. all five LOCO classes, with logical and structural results separated;
2. one non-LOCO industrial object class with component relations;
3. one texture or medical class where the entity branch should safely abstain;
4. K in {1, 2, 4, 8} and at least five nested support seeds;
5. C0 baseline, C1 single-entity, C2 fixed multi-entity atoms/simple AND/OR,
   and C3 searched monotone program, where C3 must beat C2 rather than merely
   beat C0;
6. no material structural-anomaly regression and no support/test leakage.

## Required visual evidence

Every maintained evaluation must export quantitative charts and a manifest-
selected qualitative panel.  Samples are stratified by class and anomaly
family and selected by a deterministic score rule, never by visual appeal.
RGB and masks use the same Resize(448,448) -> CenterCrop(392,392) geometry as
INP-Former. Baseline and comparator maps share one global scale; signed
difference maps use a zero-centered global scale.

The baseline augmentation comparison is generated by
`scripts/visualize_loco_checkpoint_comparison.py`. Once C1--C3 are executable,
the same report must add detected entities, each atom/witness map, the symbolic
map, the fused map, the triggered rule and its calibrated support bound.
